# SEUIF97 WebAssembly (WASM) Technical Documentation

The SEUIF97 library is compiled to WebAssembly using `wasm-bindgen`, enabling high-performance thermodynamic property calculations directly in web browsers.

The NPM package `seuif97` provides a convenient distribution mechanism for these WASM bindings.

## 1. Architecture Overview

```
┌─────────────────────────────────────────────────────────────────┐
│                      JavaScript / TypeScript                     │
│                  (Browser or Node.js Environment)               │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│                   wasm-bindgen JS Glue Code                      │
│                    (pkg/seuif97.js)                              │
│  - Module initialization (async init())                         │
│  - Memory management                                             │
│  - Type marshalling (f64 ↔ JavaScript Number)                   │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│                   WebAssembly Binary (WASM)                      │
│                    (pkg/seuif97_bg.wasm)                         │
│  - Compiled Rust code                                            │
│  - All thermodynamic calculations                                │
│  - ~300-400 KB compressed                                        │
└─────────────────────────────────────────────────────────────────┘
```

## 3. Building the WASM Module

### 3.1 Prerequisites

```bash
# Install wasm-pack (recommended)
cargo install wasm-pack

# Or install wasm-bindgen-cli directly
cargo install wasm-bindgen-cli
```

```bash
rustup target add wasm32-unknown-unknown  
```

### 3.2 build with wasm-bindgen

```bash
# 1. Build Rust library for WASM target
cargo build --release --features wasm --target wasm32-unknown-unknown

# 2. Generate JS bindings for web
wasm-bindgen target/wasm32-unknown-unknown/release/seuif97.wasm --out-dir pkg --target web
```

## 5. API Reference

### 5.1 Universal Functions (with o_id parameter)

These functions accept an input property pair plus a property ID to calculate the desired output property.

| Function | Input Parameters | Output | Description |
|----------|-----------------|--------|-------------|
| `pt(p, t, o_id)` | Pressure (MPa), Temperature (°C) | Property value | Most common input pair |
| `ph(p, h, o_id)` | Pressure (MPa), Enthalpy (kJ/kg) | Property value | Known enthalpy |
| `ps(p, s, o_id)` | Pressure (MPa), Entropy (kJ/(kg·K)) | Property value | Known entropy |
| `pv(p, v, o_id)` | Pressure (MPa), Volume (m³/kg) | Property value | Extended pair |
| `th(t, h, o_id)` | Temperature (°C), Enthalpy (kJ/kg) | Property value | Extended pair |
| `ts(t, s, o_id)` | Temperature (°C), Entropy (kJ/(kg·K)) | Property value | Extended pair |
| `tv(t, v, o_id)` | Temperature (°C), Volume (m³/kg) | Property value | Extended pair |
| `hs(h, s, o_id)` | Enthalpy (kJ/kg), Entropy (kJ/(kg·K)) | Property value | Thermodynamic cycles |
| `px(p, x, o_id)` | Pressure (MPa), Quality (0-1) | Property value | Saturation region only |
| `tx(t, x, o_id)` | Temperature (°C), Quality (0-1) | Property value | Saturation region only |
| `hx(h, x, o_id)` | Enthalpy (kJ/kg), Quality (0-1) | Property value | Saturation region only |
| `sx(s, x, o_id)` | Entropy (kJ/(kg·K)), Quality (0-1) | Property value | Saturation region only |

### 5.2 Direct Property Functions

These functions directly calculate a specific property without requiring the property ID parameter.

#### Pressure-Based Functions

```javascript
pt2h(p, t)  // Pressure + Temperature → Enthalpy
pt2s(p, t)  // Pressure + Temperature → Entropy
pt2v(p, t)  // Pressure + Temperature → Specific Volume
pt2x(p, t)  // Pressure + Temperature → Quality

ph2t(p, h)  // Pressure + Enthalpy → Temperature
ph2s(p, h)  // Pressure + Enthalpy → Entropy
ph2v(p, h)  // Pressure + Enthalpy → Specific Volume
ph2x(p, h)  // Pressure + Enthalpy → Quality

ps2t(p, s)  // Pressure + Entropy → Temperature
ps2h(p, s)  // Pressure + Entropy → Enthalpy
ps2v(p, s)  // Pressure + Entropy → Specific Volume
ps2x(p, s)  // Pressure + Entropy → Quality

pv2t(p, v)  // Pressure + Volume → Temperature
pv2h(p, v)  // Pressure + Volume → Enthalpy
pv2s(p, v)  // Pressure + Volume → Entropy
pv2x(p, v)  // Pressure + Volume → Quality
```

#### Enthalpy-Entropy Functions

```javascript
hs2p(h, s)  // Enthalpy + Entropy → Pressure
hs2t(h, s)  // Enthalpy + Entropy → Temperature
hs2v(h, s)  // Enthalpy + Entropy → Specific Volume
hs2x(h, s)  // Enthalpy + Entropy → Quality
```

#### Temperature-Based Functions

```javascript
th2p(t, h)  // Temperature + Enthalpy → Pressure
th2s(t, h)  // Temperature + Enthalpy → Entropy
th2v(t, h)  // Temperature + Enthalpy → Specific Volume
th2x(t, h)  // Temperature + Enthalpy → Quality

ts2p(t, s)  // Temperature + Entropy → Pressure
ts2h(t, s)  // Temperature + Entropy → Enthalpy
ts2v(t, s)  // Temperature + Entropy → Specific Volume
ts2x(t, s)  // Temperature + Entropy → Quality

tv2p(t, v)  // Temperature + Volume → Pressure
tv2h(t, v)  // Temperature + Volume → Enthalpy
tv2s(t, v)  // Temperature + Volume → Entropy
tv2x(t, v)  // Temperature + Volume → Quality
```

#### Saturation Region Functions

```javascript
// Pressure-Quality pair
px2t(p, x)  // Pressure + Quality → Temperature
px2h(p, x)  // Pressure + Quality → Enthalpy
px2s(p, x)  // Pressure + Quality → Entropy
px2v(p, x)  // Pressure + Quality → Specific Volume

// Temperature-Quality pair
tx2p(t, x)  // Temperature + Quality → Pressure
tx2h(t, x)  // Temperature + Quality → Enthalpy
tx2s(t, x)  // Temperature + Quality → Entropy
tx2v(t, x)  // Temperature + Quality → Specific Volume

// Enthalpy-Quality pair
hx2p(h, x)  // Enthalpy + Quality → Pressure
hx2t(h, x)  // Enthalpy + Quality → Temperature
hx2s(h, x)  // Enthalpy + Quality → Entropy
hx2v(h, x)  // Enthalpy + Quality → Specific Volume

// Entropy-Quality pair
sx2p(s, x)  // Entropy + Quality → Pressure
sx2t(s, x)  // Entropy + Quality → Temperature
sx2h(s, x)  // Entropy + Quality → Enthalpy
sx2v(s, x)  // Entropy + Quality → Specific Volume
```

### 5.3 Thermodynamic Process Functions

The following thermodynamic process functions are also available:

| Function | Input Parameters | Output | Description |
|----------|------------------|--------|-------------|
| `ishd(pi, ti, pe)` | Inlet pressure (MPa), Inlet temperature (°C), Outlet pressure (MPa) | Enthalpy drop (kJ/kg) | Isentropic enthalpy drop |
| `ief(pi, ti, pe, te)` | Inlet pressure (MPa), Inlet temperature (°C), Outlet pressure (MPa), Outlet temperature (°C) | Efficiency (%) | Isentropic efficiency |

## 6 Usage

```javascript
import init, { ishd, ief } from 'seuif97';

await init();

// Inlet conditions
const pi = 16.0;  // MPa
const ti = 535.1; // °C

// Outlet pressure
const pe = 5.0;   // MPa

// Isentropic enthalpy drop
const deltaH = ishd(pi, ti, pe);
console.log(`Isentropic enthalpy drop: ${deltaH.toFixed(3)} kJ/kg`);

// Isentropic efficiency
const te = 350.0; // °C (actual outlet temperature)
const efficiency = ief(pi, ti, pe, te);
console.log(`Isentropic efficiency: ${efficiency.toFixed(2)}%`);
```
