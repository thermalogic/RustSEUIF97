# SEUIF97 WebAssembly (WASM)

The SEUIF97 library is compiled to WebAssembly using `wasm-bindgen`, enabling high-performance thermodynamic property calculations directly in web browsers.

The NPM package `seuif97` provides a convenient distribution mechanism for these WASM bindings.

## Architecture Overview

```
┌─────────────────────────────────────────────────────────────────┐
│                      JavaScript / TypeScript                    │
│                  (Browser or Node.js Environment)               │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│                   wasm-bindgen JS Glue Code                     │
│                    (pkg/seuif97.js)                             │
│  - Module initialization (async init())                         │
│  - Memory management                                            │
│  - Type marshalling (f64 ↔ JavaScript Number)                   │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│                   WebAssembly Binary (WASM)                     │
│                    (pkg/seuif97_bg.wasm)                        │
│  - Compiled Rust code                                           │
│  - All thermodynamic calculations                               │
│  - ~300-400 KB compressed                                       │
└─────────────────────────────────────────────────────────────────┘
```

## 2. NPM Package Structure

```
npm/
├── package.json              # NPM package configuration
├── README.md                 # Usage documentation
└─── pkg/                      # Generated by wasm-bindgen (do not edit)
    ├── seuif97.js           # JS glue code
    ├── seuif97_bg.js        # WASM loader
    ├── seuif97_bg.wasm      # Compiled WebAssembly binary
    ├── seuif97.d.ts         # TypeScript type definitions
    └── seuif97_bg.wasm.d.ts # WASM binary type declarations
```

## Prerequisites

```bash
# Required
cargo install wasm-bindgen-cli
```

```bash
# Optional (alternative)
cargo install wasm-pack
```

```bash
rustup target add wasm32-unknown-unknown  
```

## Build WASM(ES Modules) with wasm-bindgen

1. Build Rust library for WASM target

```bash
cargo build --release --features wasm --target wasm32-unknown-unknown
```

2. Generate JS bindings for web
```bash
wasm-bindgen target/wasm32-unknown-unknown/release/seuif97.wasm --out-dir pkg --target web
```

## NPM(ES modules) Package 

```bash
cd npm
```

* Build NPM Package

```bash
npm run build:wasm
```

* Publish NPM Package

```bash
npm login
npm publish
```

### JavaScript Example

```javascript
// node demo_wasm_simple.js
// import init, { pt } from './node_modules/seuif97/pkg/seuif97.js'; // node_modules
import init, { pt } from '../../pkg/seuif97.js';  // local pkg
import { readFileSync } from 'fs';
import { fileURLToPath } from 'url';
import { dirname, join } from 'path';

const __dirname = dirname(fileURLToPath(import.meta.url));

// const wasmPath = join(__dirname, 'node_modules', 'seuif97', 'pkg', 'seuif97_bg.wasm'); // node_modules
const wasmPath = join(__dirname, '..', '..', 'pkg', 'seuif97_bg.wasm'); //local pkg
const wasmBuffer = readFileSync(wasmPath);

await init({ module_or_path: wasmBuffer });

const p = 16.0;
const t = 535.1;
const h = pt(p, t, 4);

console.log(`p = ${p} MPa, t = ${t} °C`);
console.log(`h = ${h.toFixed(3)} kJ/kg`);
```
