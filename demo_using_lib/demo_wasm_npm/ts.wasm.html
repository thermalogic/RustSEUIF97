📖 使用说明

T-S 图显示水蒸气的温度-熵关系，包含以下曲线：

  • 等焓线：绿色曲线，焓值从 200 到 3600 kJ/kg
  • 等压线：蓝色曲线，压力从 0.000611657 到 100 MPa
  • 饱和线：红色实线，饱和液体线 (x=0) 和饱和蒸汽线 (x=1)
  • 等干度线：红色虚线，干度从 0.1 到 0.9
